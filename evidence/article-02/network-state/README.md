# Article 02 network-state evidence

- [`LATEST.json`](LATEST.json) points to the current validator, delegator and stake snapshot.
- [`block-13431722/`](block-13431722/) contains raw provider responses, validator/delegator CSVs, concentration metrics, manifests and SHA-256 checksums used by Article 02.

Publication values are rounded to two decimals; machine-readable evidence retains full precision. Address-level delegator metrics are not beneficial-owner metrics. See [`methodology/consensus.md`](../../../methodology/consensus.md).
